# 算法核心解题框架注意事项

## 0704（双指针-链表相关）
1. **合并两个有序链表（MergeTwoSortedLists）**
    - 借助虚拟指针技巧**：通过虚拟头节点（dummy）简化边界处理，用两个指针分别遍历两个链表，每次选择较小节点连接到结果链表。
    - 终止处理：当其中一个链表遍历完毕，直接将另一个链表剩余部分接接到到结果链表尾部。

2. **合并K个有序链表（MergeKSortedLists - 优先队列实现）**
    - 利用优先队列（小顶堆）维护当前各链表的最小节点，每次取出最小节点并将其下一个节点加入队列。
    - 注意空链表处理：初始入队时需过滤空链表，避免空指针异常。
    - 时间复杂度：O(N log K)，其中N为总节点数，K为链表数量，每次堆操作耗时O(log K)。

## 0705（双指针-数组相关）
1. **移动零（MoveZeroes）**
    - 快慢指针分工：快指针遍历数组，慢指针标记非零元素存放位置，遍历结束后将慢指针之后的位置填充为0。
    - 优化点：避免不必要的元素交换，直接覆盖赋值后统一补0，减少操作次数。

2. **两数之和II（TwoSumIiInputArrayIsSorted）**
    - 左右指针收缩：利用数组有序特性，左指针从起点、右指针从终点开始，根据两数之和与目标值的大小关系移动指针。
    - 索引处理：题目要求返回1-based索引，需注意结果加1转换。

3. **两数之和（TwoSum - 暴力解法）**
    - 双层循环遍历所有可能组合，时间复杂度O(N²)，适用于理解基础思路，实际优化需用哈希表（O(N)）。


## 0707（二叉树基础）
1. **二叉树前序遍历（BinaryTreePreorderTraversal）**
    - 递归框架：遵循“根-左-右”顺序，先访问根节点，再递归遍历左右子树。
    - 空节点处理：递归终止条件为节点为空，避免空指针异常。
    - 结果收集：通过外部列表存储遍历结果，递归过程中逐步添加节点值。


## 0708（动态规划入门）
1. **斐波那契数（FibonacciNumber）**
    - 备忘录优化：用数组存储已计算的子问题结果，避免重复递归计算，将时间复杂度从O(2ⁿ)降至O(N)。
    - 边界条件：明确n=0返回0，n=1返回1，作为递归终止条件。


## 0712（BFS框架）
1. **打开转盘锁（OpenTheLock - 辅助函数）**
    - 密码拨动逻辑：实现单个数字的向下拨动（0→9，其他数字减1），作为BFS中生成邻接节点的基础操作。
    - 字符串处理：通过字符数组转换实现单个位置的修改，避免字符串不可变带来的性能损耗。


## 0713（回溯算法-排列、组合、子集）
1. **组合（Combinations）**
    - 递归起点控制：通过start参数限制下一层遍历的起点，避免生成重复组合（如[1,2]与[2,1]视为同一组合）。
    - 终止条件：当路径长度达到k时，收集结果并返回。

2. **组合总和（CombinationSum）**
    - 元素可重复使用：递归时start参数不变（允许再次选择当前元素），但需注意剪枝（和超过目标值时提前返回）。
    - 路径和跟踪：用变量实时记录当前路径总和，避免重复计算总和。

3. **组合总和II（CombinationSumIi）**
    - 去重处理：先排序数组，再通过“i > start && nums[i] == nums[i-1]”跳过重复元素，避免相同组合。
    - 元素不可重复使用：递归时start参数+1，确保每个元素仅用一次。

4. **子集（Subsets）**
    - 所有子集收集：在递归开始即收集当前路径（包含空集），通过start参数控制元素选择范围，避免重复子集。

5. **子集II（SubsetsIi）**
    - 重复子集去重：同组合总和II，排序后跳过相同元素，确保每个子集唯一。

6. **全排列（Permutations）**
    - 已用元素标记：通过boolean数组记录元素是否已加入路径，避免重复使用元素。
    - 无顺序限制：每次递归从0开始遍历，但跳过已使用元素，生成所有可能排列。

7. **全排列II（PermutationsIi）**
    - 重复排列去重：排序后，当“nums[i] == nums[i-1]且前一个元素未使用”时跳过，确保相同元素相对位置固定，避免重复排列。


## 0715（分治算法）
1. **合并K个有序链表（MergeKSortedLists - 分治实现）**
    - 分治思想：将K个链表不断二分，转化为合并两个有序链表的子问题，最终合并所有结果。
    - 递归边界：当start == end时，直接返回单个链表；否则递归合并左右两部分。
    - 时间复杂度：O(N log K)，通过分治将K次合并优化为log K层，每层合并总节点数为N。
